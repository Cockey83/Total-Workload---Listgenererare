# Total Workload Listgenererare

Detta projekt är en React-app för att generera listor baserat på Excel-uppladdningar. Appen stöder kategorispecifik filtrering och anpassad datahantering.

## Installation

1. Klona detta repository:
   ```bash
   git clone <repo-url>
   ```

2. Installera nödvändiga paket:
   ```bash
   npm install
   ```

3. Starta utvecklingsservern:
   ```bash
   npm start
   ```

## Funktioner
- Filuppladdning och kategorival
- Automatisk filtrering baserat på kategorier
- Dynamisk generering av HTML-tabeller

## Tekniker
- React
- Tailwind CSS
- XLSX (för Excel-parsing)
